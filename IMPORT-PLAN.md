# Previous Site Work Import Plan

This branch is reserved for consolidating the user's previous web projects into the Thika Church / web studio project. Existing projects should be integrated deliberately rather than replacing the current application wholesale.

## Projects identified
- OmpathStudy Medical Hub — ompathstudy.com
- MKU Christian Union
- Victory School Club
- KMPDU
- Kenyan Medical Library
- Kenya Classifieds / Bazaar Kenya
- KASNEB / Kenya Notes Hub
- Avant Movies
- NexaWeb Studio VOD
- Azani ISP Project

## Integration approach
1. Preserve the current application and its working routes.
2. Bring over reusable portfolio content, project metadata, screenshots/assets, and documented features from the previous repositories.
3. Avoid copying secrets, .env values, deployment-specific credentials, or unrelated production configuration.
4. Organize the projects into a clear portfolio/catalogue so each previous site is represented.
5. Validate links and assets before merging the branch into main.
